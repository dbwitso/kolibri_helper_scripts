# Helper Scripts for the deployment of Kolibri

## LSHE centre servers

[`lshe/`](lshe/) has the scripts for LSHE (Life Skills and Health Education)
centre servers: MindSpark roster import, channel import, grade bands, and the
monthly report, plus central report collection. They run against Edulution's
Kolibri fork in Docker. See [`lshe/README.md`](lshe/README.md).
